# Requirements review — October 27, 2026

This review compares the current implementation with the owner's original brief.
The [requirement register](ROADMAP.md) retains every requested feature. A partially
implemented row stays open; source inspection is not full user acceptance.

| Area | Evidence and alignment | Remaining work / qualification |
|---|---|---|
| Native/local architecture | Swift 6, SwiftUI/AppKit, rational model, immutable snapshots, AVFoundation/Core Image/Core Text/Accelerate; local files and rendering. | Native document integration and broad failure cases remain open. No account/cloud/upload/subscription added. |
| Icon-led workspace | Charcoal shell, thin SF Symbol toolbar, large output, collapsible inspector, full-width layered timeline, focus shortcut; real preset thumbnails. | This pass fixes inaccessible timeline collapse and angle previews over the output. Full 1280-window/manual VoiceOver/target-size coverage still required. |
| Direct editing | Viewer transform/crop/drawing paths, clip edges, fades, automation points and numeric alternatives exist. | General keyframes, animated reframing, broader linked edits and complete in-place text/keyboard workflows remain open. |
| Editing safety | Explicit placement previews, locks/source checks, undoable commands and preservation of gaps. | This pass fixes unchecked clipboard arithmetic and clip-only gating of text Copy/Cut. Broader splice/failure tests remain required. |
| Music/multicam | Waveforms, beat/manual grids, reviewed sync/drift, persistent master, four proxy players, armed switching and editable decisions have native fixtures. | Loop crossfades, reverse, speed ramps, metronome and representative long real performances remain open. |
| Creator tools | Original looks/transitions, adjustment layers, background/typography controls, reusable layouts, SRT, shapes/drawing and shared colors exist. | Advanced color, stickers, word timing/highlights, full typography and general animation remain open. |
| Preview/export | Shared render/audio plans; native decoded frame/sample comparisons; snapshot/temp-destination export. | HDR/VFR/metadata breadth, full shipped format matrix and all required workflows remain open. |
| Projects/media | Versioned packages, schema 7 protection, relink/bookmarks/collect/recovery, pinned local-only LGPL helpers. | Machine-transfer/failure coverage and native document command completion remain open. |
| Public presentation | README contains actual exported frames, reproducible projects and an honest progress link. | Running-app screenshots omitted until genuine capture is available; no reconstructed UI. |
| Release quality | Local tests, optimized app and hosted CI are verified per delivery. | M1 measurements, usability, complete accessibility and manual install/smoke gates remain unpassed. Current app is ad-hoc, not notarized. |

The original minimal-text rule still applies: explanations belong in documentation,
not persistent paragraphs in the editing workspace. Icons need accessible names,
tooltips and visible non-color states; using icons alone does not establish
usability. The [public-preview plan](PUBLIC-PREVIEW.md) separates this week's early
release from the complete 1.0 roadmap.
